# 人格卡

## 它是什么

一张“这个 QQ 号该以什么身份、什么语气说话”的行为规则。服务启动时读一次；改完要重启服务。

**仓库里没有卡。** 你的卡放在运行目录：

```text
%USERPROFILE%\.dsh\qq-agent\persona.md
```

Linux/macOS：`~/.dsh/qq-agent/persona.md`。

## 支持格式

| 扩展名 | 内容 |
|---|---|
| `.md` / `.markdown` / `.txt` | 纯文本 / Markdown，整段作为角色设定 |
| `.json` | SillyTavern V2/V3 卡，或 `{name, description, personality, scenario, ...}` 扁平对象 |
| `.png` | SillyTavern PNG 卡，读 `chara` / `ccv3` 文本块（base64 JSON） |

JSON/PNG 会渲染成：

```text
# 角色名
## 角色设定
## 性格
## 场景
## 系统指令
## 补充指令
## 开场白（只作语气参考，不要自动发送）
## 示例对话（只作语气参考）
```

`character_book` 目前不展开，只在状态里给一条警告；“世界书”式的长设定请直接写进 `description`。

## 校验规则

- 80–20,000 字；
- 不能含 NUL；
- 不能留着 `TODO`、`<角色名>`、`{{name}}` 这类占位符；
- 读不到/格式不支持 → 启动失败，退出码 2，面板显示“未配置”。

检查命令：

```powershell
qq-agent persona --check
```

它只打印名字、格式、字数和路径，**不打印卡内容**。

## 写一张好用的卡

1. 只写**行为规则**，不写小说设定。模型需要知道“怎么说话”，不是“发生过什么”。
2. 句子长度、称呼、口癖、什么时候收住，写具体判准，不要写“温柔一点”。
3. 写边界：不编造、不替人做重大决定、不做医疗/法律诊断、不生成色情内容。
4. 不要把真实姓名、电话、地址、身份证号、密钥写进卡。运行目录是本地的，但卡也可能被你自己误传。
5. 角色版权由你负责。不要把自己没有权利使用的角色卡公开分发。

## 格式模板

仓库里的 [`persona.example.md`](../persona.example.md) 只是模板，带着占位符，不能直接启动。复制到 `persona.md` 后把所有占位符替换掉。

## 为什么没有内置卡

上游私有版本里有两张卡，其中一张还带着号主的年龄、学校、生日等真实信息。公开包不能复用它们：

- 代码里不保留任何预置人设；
- 没有“预设名”回退；
- 没有卡就失败，而不是悄悄用某个默认角色；
- 面板不解析卡内容，昵称单独用 `[qq].display_name` 配置。

你的卡继续留在自己的运行目录，仓库和插件里都不会出现。
